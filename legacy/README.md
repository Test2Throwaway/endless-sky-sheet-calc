# Legacy

Original ship designer spreadsheets, put together partly by hand, preserved as-is for reference.

- `Ship_designer_master_sheet.ods` — **most up to date version** (last saved 2026-10-15).
  23 sheets: Worksheet instructions, Stats overview, outfit data sheets (Drives, Jammers,
  Scanners, Fuel, Generators, Batteries, Cooling, Engines, Shields, Cargo & Outfit Expansions,
  Anti-Missile, Utility Weapons_*, Damage Weapons), and Magic Numbers (named constants used
  by the "Heat compensated Outfit Space" formulas).
- `Ship_designer_master_sheet.xlsx` — older, less complete export (20 sheets, no instructions
  sheet, no Magic Numbers / heat-compensated formulas).
